# EXAMEN DE PROGRAMACIÓN VISUAL - Los Simpson 🍩

## 📝 Descripción del Proyecto
La aplicación **Los Simpson - Explorador de Personajes** es una herramienta desarrollada en **JavaFX** que consume una API REST para mostrar información detallada de la serie. Permite filtrar personajes, obtener resultados aleatorios y visualizar datos mediante una interfaz moderna y paginada.
